      COLMAP parameters
      
        
      
      
      
      
        
      These controls tune how COLMAP estimates camera poses:
      
        
        
          
      • Matcher: Sequential links neighboring images (ideal for drone flights). Exhaustive compares every pair (slower but can recover unordered sets).
        • 
          
      • Sequential overlap: Number of neighboring frames to compare when using sequential matching. Increase to strengthen weak overlaps.
        • 
          
      • Min triangulation angle: Rejects points with small viewing angle. Higher values improve accuracy but may drop matches. Default 5° works for most flights.
        • 
          
      • Min model size: Smallest number of registered images required before COLMAP keeps a reconstruction. Raise this to ignore tiny, fragmented models.
        • 
          
      • Max feature image size: Downsamples large frames before feature extraction. Helpful for noisy thermal sensors; leave blank to use the original size.
        • 
          
      • Use GPU for SIFT: Disable if the GPU driver causes instability; COLMAP will fall back to CPU features.
        • 
          
      • Camera model: Choose the projection model COLMAP assumes when reading EXIF. Thermal DJI frames usually work with SIMPLE_RADIAL.
        • 
          
      • Min matches / inliers: Tune the minimum matches per image plus the inlier thresholds COLMAP uses when seeding models or registering new views.
        • 
          
      • Model overlap / count: Limit how many reconstructions COLMAP keeps and how much overlap they can share so it stays focused on your main flight.
        •

          Parameter notes
          
        
            
      • Camera model: SIMPLE_RADIAL for most thermal DJI flights.
        • 
            
      • Triangulation: Higher prunes weak geometry; lower accepts more points.
        • 
            
      • Matches / inliers: Tighten to reject weak registrations; loosen for low-texture.
        • 
            
      • SIFT thresholds: Lower peak → more features; edge≈8 suits thermal.
        • 
            
      • Block size: Exhaustive only; smaller reduces RAM at cost of more steps.
        • 
            
      • BA refine: Keep ON unless you have strong prior intrinsics.
        • 
            
      • Thermal BA: Set max reproj error 12+, BA iters 15/10 to prevent crash.
